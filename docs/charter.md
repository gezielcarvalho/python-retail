# Charter

## Purpose

Demonstrate Python data-analysis and engineering skills through retail business questions, visual storytelling, reusable modules, and quality tooling.

## Audience

Portfolio reviewers, technical collaborators, and learners evaluating pandas-based analytical workflows.

## Success criteria

- Analysis questions and results remain easy to discover.
- Reusable package code supports notebook narratives.
- Future roadmap work increases engineering depth without obscuring the exploratory workflow.
