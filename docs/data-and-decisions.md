# Data and decisions

## Data boundary

The tracked retail dataset is used only for this analytical showcase. Do not add private customer, commercial, or production data without an explicit provenance, licensing, and privacy review.

## Decisions

- Preserve the notebook-per-question storytelling approach.
- Continue moving repeated analytical logic into `src/retail_analytics/` as described in the roadmap.
- Treat forecasting, segmentation, a CLI, and a dashboard as separately scoped future enhancements.
