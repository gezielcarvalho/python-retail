# Delivery and quality

## Local workflow

- Create a Python 3.12+ virtual environment.
- Install the package and dependencies with `pip install -e .`.
- Use Jupyter Lab for notebook exploration.
- Use `make install-dev`, `make test`, `make lint`, and `make format` for development work where available.

## Quality boundary

Run focused tests and quality checks when Python code changes. Documentation-only changes require whitespace validation and reviewer inspection.
